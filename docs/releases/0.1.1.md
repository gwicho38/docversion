# docversion 0.1.1

## Fixed

- `bump --note` now labels the version being opened, not the version being frozen (#1).
- History keeps one row per version. Freezing refreshes the frozen version's row (file, sha256) instead of appending a duplicate row with the same version number.
- `restore` records a row for the restored-as version ("restored from vN — note") and no longer appends an "(auto-frozen before restore)" duplicate.

## Changed

- `bump --note` help text: "Label for the new version being opened."
- README examples updated to match.

## Diff summary

| File | Change |
|---|---|
| `src/docversion/core.py` | Add `record_frozen` and `record_opened`. |
| `src/docversion/cli.py` | `bump` and `restore` use them. |
| `tests/test_cli.py` | Four regression tests plus a `--skip-unchanged` guard. |

## Existing manifests

Manifests written by 0.1.0 may hold duplicate rows. They still load and work. `log` shows them as they are; edit `.docversion.json` by hand to tidy old history.
